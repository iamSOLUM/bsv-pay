# bsvpay

Alias package for [`bsv-pay-cli`](https://www.npmjs.com/package/bsv-pay-cli) —
a developer-first CLI and agent payment toolkit for BSV micropayments.

```bash
npm install -g bsvpay
bsv-pay --help
```

Installs the same `bsv-pay` (and `bsvpay`) binary by depending on
`bsv-pay-cli` at the exact same version. Install one or the other, not both
globally — they provide the same binaries and would collide.

Full documentation: <https://github.com/iamSOLUM/bsv-pay#readme>
